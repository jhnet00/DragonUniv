## 작업 배경

기존 구조에서는 학생 영역과 관리자 영역이 같은 `AppShell` 레이아웃 안에 혼재되어 있었음.
`/admin` 경로가 곧바로 관리자 대시보드를 보여줬기 때문에 로그인 없이 접근 가능한 구조였고,
관리자 페이지와 학생 페이지의 사이드바/헤더가 동일하게 보이는 문제가 있었음.

목표: 
- `/admin` 접근 시 반드시 관리자 로그인 페이지가 먼저 표시되도록 변경
- 관리자 전용 레이아웃(`AdminShell`)을 분리하여 관리자 메뉴만 표시
- 모든 관리자 하위 페이지를 `/admin/*` 경로로 통일

---

## 변경 전 라우팅 구조

```
/           → Landing
/login      → 학생 로그인
/admin-login → 관리자 로그인   ← 별도 경로 존재
/register   → 수강신청 (AppShell)
/classroom  → 나의 강의 (AppShell)
/profile    → 프로필 (AppShell)
/notices    → 공지사항 (AppShell)
/monitoring → 시스템 상태 (AppShell)
/admin      → 관리자 대시보드 (AppShell - 학생과 같은 레이아웃)
/admin/courses → 강의 관리 (AppShell)
```

**문제점:**
- `/admin`이 로그인 없이 대시보드로 바로 진입
- 관리자 페이지가 학생 AppShell(사이드바에 수강신청·나의 강의 등) 안에 표시됨
- `/admin-login`이라는 별도 경로가 있어 URL 구조가 비직관적

## 변경 후 라우팅 구조

```
/                  → Landing
/login             → 학생 로그인
/admin             → 관리자 로그인  ← /admin 진입 시 로그인 먼저

[학생 영역 - AppShell]
/register          → 수강신청
/classroom         → 나의 강의
/courses/:id       → 강의 상세
/profile           → 프로필
/notices           → 공지사항
/notices/:id       → 공지 상세
/monitoring        → 시스템 상태

[관리자 영역 - AdminShell]
/admin/dashboard   → 관리자 대시보드
/admin/courses     → 강의 관리
/admin/monitoring  → 시스템 모니터링 (관리자용)
```

## 파일별 상세 변경 내용

### 1. `src/App.tsx`

- `AppShell` 안에 있던 `/admin`, `/admin/courses` 라우트를 제거
- `AdminShell` import 추가
- `/admin` 경로를 `<Login type="admin" />`으로 변경 (로그인 페이지)
- `/admin-login` 경로 삭제
- 관리자 전용 `<Route element={<AdminShell />}>` 블록 신규 추가
  - `/admin/dashboard` → `AdminDashboard`
  - `/admin/courses` → `AdminCourses`
  - `/admin/monitoring` → `Monitoring`

### 2. `src/components/AdminShell.tsx` (신규 생성)

- 기존 `AppShell`을 참고하여 관리자 전용 레이아웃 컴포넌트 신규 작성
- 헤더 타이틀: "관리자페이지"
- 로그아웃 클릭 시 `/admin` (관리자 로그인 페이지)으로 이동
- 사이드바 메뉴 (학생 메뉴와 완전히 분리):
  - 대시보드 (`/admin/dashboard`)
  - 강의 관리 (`/admin/courses`)
  - 시스템 모니터링 (`/admin/monitoring`)

### 3. `src/components/AppShell.tsx`

- 기존 사이드바 메뉴에서 "관리자" 항목 (`/admin` 링크) 제거
- 학생 사이드바에 관리자 링크가 노출되던 문제 해결
- `lucide-react` import에서 더 이상 사용하지 않는 `Gauge` 아이콘 제거

### 4. `src/pages/Login.tsx`

- 관리자 로그인 성공 후 리다이렉트 경로 변경
  - 변경 전: `/admin`
  - 변경 후: `/admin/dashboard`

## 비고 / 후속 과제

- 현재 로그인은 mock 처리 (어떤 값이든 입력하면 통과). 실제 인증 연결 시 라우트 가드(`PrivateRoute`) 추가 필요
- `node_modules` 미설치 상태 — Node.js 설치 후 `Frontend/` 디렉토리에서 `npm install` 실행 필요
- 학생용 `/monitoring`과 관리자용 `/admin/monitoring`은 현재 동일한 `Monitoring` 컴포넌트를 재사용 중
