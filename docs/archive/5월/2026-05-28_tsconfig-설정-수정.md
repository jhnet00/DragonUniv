## 작업 배경

Node.js 설치 후 IDE에서 다수의 TypeScript 오류가 발생함.  
`lucide-react`, `react-router-dom` 등 주요 패키지의 import에 빨간 줄이 표시되며  
`'모듈 또는 해당 형식 선언을 찾을 수 없습니다.'` 오류가 출력됨.

**원인:**  
`"moduleResolution": "Node"` 설정이 문제.  
React 19, react-router-dom v7, framer-motion v12 등 최신 패키지들은  
`package.json`의 `exports` 필드를 사용하는데, `Node` 방식은 이를 인식하지 못함.  
Vite 기반 프로젝트는 `"moduleResolution": "bundler"` 를 사용해야 함.

---

## 변경 내용

### `Frontend/tsconfig.json`

**변경 전:**
```json
{
  "compilerOptions": {
    "target": "ES2020",
    "useDefineForClassFields": true,
    "lib": ["DOM", "DOM.Iterable", "ES2020"],
    "allowJs": false,
    "skipLibCheck": true,
    "esModuleInterop": true,
    "allowSyntheticDefaultImports": true,
    "strict": true,
    "forceConsistentCasingInFileNames": true,
    "module": "ESNext",
    "moduleResolution": "Node",
    "resolveJsonModule": true,
    "isolatedModules": true,
    "noEmit": true,
    "jsx": "react-jsx"
  },
  "include": ["src"],
  "references": []
}
```

**변경 후:**
```json
{
  "compilerOptions": {
    "target": "ES2020",
    "useDefineForClassFields": true,
    "lib": ["ES2020", "DOM", "DOM.Iterable"],
    "module": "ESNext",
    "moduleResolution": "bundler",
    "allowImportingTsExtensions": true,
    "moduleDetection": "force",
    "isolatedModules": true,
    "noEmit": true,
    "jsx": "react-jsx",
    "strict": true,
    "skipLibCheck": true
  },
  "include": ["src"]
}
```

## 항목별 변경 상세

| 옵션 | 변경 전 | 변경 후 | 이유 |
|------|---------|---------|------|
| `moduleResolution` | `"Node"` | `"bundler"` | Vite 프로젝트 표준. 최신 패키지의 `exports` 필드 인식 필요 |
| `allowImportingTsExtensions` | 없음 | `true` | `.ts` / `.tsx` 확장자 import 허용 (Vite bundler 모드 필수) |
| `moduleDetection` | 없음 | `"force"` | 모든 파일을 모듈로 강제 인식, 전역 스코프 오염 방지 |
| `esModuleInterop` | `true` | 제거 | `bundler` 모드에서 불필요 |
| `allowSyntheticDefaultImports` | `true` | 제거 | `bundler` 모드에서 불필요 |
| `forceConsistentCasingInFileNames` | `true` | 제거 | `strict: true`에 포함됨 |
| `allowJs` | `false` | 제거 | 기본값과 동일하여 불필요 |
| `resolveJsonModule` | `true` | 제거 | 현재 프로젝트에서 JSON import 미사용 |
| `references` | `[]` | 제거 | 빈 배열은 의미 없음 |

수정 후 `npx tsc --noEmit` 실행 결과 오류 없이 통과.  
IDE TypeScript 서버에서 import 오류 해소 확인.
