### 3. VirtualBox VM 생성

| 항목 | 값 |
|------|-----|
| VM 이름 | `dragon-k3s` |
| OS | Ubuntu 22.04.5 LTS Server (amd64) |
| RAM | 4096 MB |
| CPU | 2코어 |
| 디스크 | 100 GB |
| 네트워크 | NAT + Port Forwarding (호스트 2222 → 게스트 22) |
| 사용자 | `dragon` |
| OpenSSH | 설치됨 |

**Unattended Installation 비활성화** 후 수동 설치 진행.

### 4. SSH config 설정

`C:\Users\userpc\.ssh\config` 에 아래 내용 추가:

```
Host dragon-k3s
    HostName 127.0.0.1
    Port 2222
    User dragon
```

이후 `ssh dragon-k3s` 명령어로 간편 접속 가능.

### 5. k3s 설치

VM 접속 후 아래 명령어로 k3s 설치:

```bash
sudo apt update && sudo apt upgrade -y
curl -sfL https://get.k3s.io | sh -
```

**설치 확인:**

```bash
kubectl get nodes
```

```
NAME          STATUS   ROLES           AGE     VERSION
dragon-k3s    Ready    control-plane   2m54s   v1.35.5+k3s1
```

`Ready` 상태 확인 완료.
